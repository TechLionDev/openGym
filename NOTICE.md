# Provenance Notice — openGym (TechLionDev restore)

This repository is a **public restore** of **openGym**, the self-hosted
gym & body-weight tracker originally published by DuarteSantos8 at
`github.com/DuarteSantos8/openGym`.

## Why this exists
- The original repository and its author account were deleted in early August 2026
  (last public snapshot archived 2026-08-01 via web.archive.org).
- The complete source was recovered from a public fork:
  `github.com/arvids-unavailable/openGym` (faithful AGPL-3.0 fork, ~364 stars).
- Re-published publicly by **TechLionDev** on 2026-08-19 as a community restore so
  the project is not lost.

## Attribution
All original copyright and credit belong to **DuarteSantos8**. This is a faithful
recovery of their work; no code was authored or modified by TechLionDev beyond
restoring the build wiring (Dockerfile path + a committed `.env.example`) so the
project builds from source out of the box.

## Original description
Self-hosted gym & body-weight tracker — plan routines, log workouts, track body
weight over time. No account on someone else's server, no subscription, no ads.
Just `docker compose up`.
